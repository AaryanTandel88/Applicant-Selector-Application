# Data Engineering (DE) Integrated Project Documentation
## RAC DRDO Adaptive Interview & Candidate Screening System

---

### Project Overview
The **RAC DRDO Adaptive Interview System** is an offline, AI-assisted candidate screening and oral interview platform built for the **Recruitment and Assessment Centre (RAC), Defence Research and Development Organisation (DRDO)** to evaluate candidates for positions like *Scientist 'C' – Advanced System Development (ASD)*.

This directory satisfies all mandatory submission requirements for the **Data Engineering (DE) Integrated Project**.
